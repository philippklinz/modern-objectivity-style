# Design Decision Record

Copy the following draft template for consequential design decisions.

```yaml
id: DDR-0001
title: ""
status: proposed # proposed | evaluated | adopted | revised | rejected
date: YYYY-MM-DD
owner: ""
stage: ""
problem: ""
user_context: ""
requirements: []
hypothesis: ""
alternatives: []
chosen_approach: ""
principles: [] # e.g. MO-03, MO-10
emotional_intent: "" # optional
prototype_reference: ""
evaluation_method: ""
success_criteria: []
observations: []
subjective_feedback: []
limitations: []
decision: ""
revision_trigger: ""
```

Record hypotheses separately from actual observations.
