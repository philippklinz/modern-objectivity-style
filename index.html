MO-13 / Language access

Understanding is part of access.

Modern Objectivity requires complete user-facing journeys in all 24 official EU languages: content, controls, explanations and feedback.

24 EU LANGUAGES
A design requirement

Build language into the interface.

Keep scientific meaning and application state intact. Let text grow, format values locally and show the actual translation coverage.

Read the central requirement
A working programming pattern

One model. Local language packs.

Switch a small sampling plan between 24 languages. Its values stay put while text, numbers, plural forms and accessible descriptions change.
