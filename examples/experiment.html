Laboratory / 002 — point · line · time

A live, testable model.

Change amplitude, frequency and phase. The line responds immediately; a movable point lets you inspect its computed value. Time advances only while the model is running.

ⓘDemonstration, not a physical instrument. Values are derived from a sinusoidal function. No sensor, network, or experiment dataset is connected.

Configuration / 01

Change the system.

Every slider changes a real function parameter. The plot and readouts share the same model.

Model parameters

LIVE CONTROLS

Model definition

EXPLICIT ASSUMPTIONS
y(x,t) = A sin(2π f x + φ − 2π · 0.2 · v · t)
A — amplitude
Output magnitude in abstract model units (not physical displacement).
f — spatial cycles
Number of cycles across x ∈ [0, 1].
φ — phase
Starting phase in radians, entered as degrees.
v — speed
A visualization rate multiplier; no physical wave speed is inferred.
Interpretation / 02

See the relation.

Point identifies the probe; line visualizes relations across space; time changes the model. The stage keeps controls and interpretation separate.

POINT

Position

The highlighted point exposes a single computed value at the selected normalized position.

LINE + SPACE

Relationship

A continuous line shows the model across space, with axes and a centerline for orientation.

TIME

Change

Playback evolves the display. Pause, single-step and reset make the state controllable.
