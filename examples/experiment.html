Model definition

EXPLICIT ASSUMPTIONS
y(x,t) = A sin(2π f x + φ − 2π · 0.2 · v · t)
A — amplitude
Output magnitude in abstract model units (not physical displacement).
f — spatial cycles
Number of cycles across x ∈ [0, 1].
φ — phase
Starting phase in radians, entered as degrees.
v — speed
A visualization rate multiplier; no physical wave speed is inferred.
