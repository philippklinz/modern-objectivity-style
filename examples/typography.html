Liberation / Web typography

One family of ideas.
Many ways to read.

Liberation gives our laboratories a consistent voice across interfaces, texts, code and languages. This site uses the actual WOFF2 files prepared by Philipp Klinz in LiberationFontsWeb, served locally with each laboratory.

Watch the subsets become available.

Choose a Greek or Bulgarian sample, or try the mathematical symbols. The monitor reads the preview's own font faces without preloading them.

SubsetCurrent textFile sizeFace status

Already loaded faces stay available while you explore. File sizes describe the stored WOFF2 files, not network traffic: the browser may reuse its cache.

Characters decide.

The browser matches family, weight, style and characters. A language can use several subsets; different languages can share one. The lang attribute describes the language, while unicode-range controls character matching.

Read while loading.

font-display: swap lets fallback text appear while the requested font becomes available. It controls display timing; it does not choose the subset.

Coverage has boundaries.

These files cover Latin, extended Latin, Greek, Cyrillic and selected mathematical symbols. Combining marks, emoji and other scripts may use fallback fonts. The math subset is not a complete equation font.

Use the same files in your laboratory.

The starter already includes the fonts. Keep its fonts folder beside modern-objectivity.css when copying it. No CDN, package runtime or build step is needed.

Include the bundle.

For a separate project, copy the font folder with its notices and load the bundle. You can also choose an individual family stylesheet.

<link rel="stylesheet"
  href="fonts/liberation/LiberationFontsWeb.css">

<!-- Or just the Sans family: -->
<link rel="stylesheet"
  href="fonts/liberation/LiberationSansWeb.css">

Assign semantic roles.

Use the Web family names. Keep generic fallbacks for unavailable fonts or characters. Request 400 or 700 when you want the supplied regular or bold face.

:root {
  --mo-font: "Liberation Sans Web", sans-serif;
  --mo-serif: "Liberation Serif Web", serif;
  --mo-mono: "Liberation Mono Web", monospace;
}
body { font-family: var(--mo-font); }
code { font-family: var(--mo-mono); }
strong { font-weight: 700; }
Inspect a subset declaration.

This is the regular Greek face from the package. Declaring it makes it available; using matching characters causes the browser to request it. Avoid preloading every subset.

@font-face {
  font-family: "Liberation Sans Web";
  src: url("LiberationSansWeb-Regular.greek.woff2")
    format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
  unicode-range: U+0370-03FF, U+1F00-1FFF;
}
Keep language and typography separate.

Use the correct lang value for pronunciation, hyphenation and language-aware tools. Selecting a font does not translate content or guarantee that every glyph is present.

<p lang="el">Η παρατήρηση γεννά γνώση.</p>
<p lang="bg">Наблюдението създава знание.</p>
<p lang="pl">Zażółć gęślą jaźń.</p>

Source, credit and reuse.

The font files are copied unchanged from Philipp Klinz's LiberationFontsWeb repository. The package records its source commit and file hashes. Sans, Serif and Mono retain the SIL Open Font License; Sans Narrow's upstream GPL license and font exception are also included.
