Start a laboratory

git clone https://github.com/philippklinz/modern-objectivity-style.git
cp -r modern-objectivity-style/starter my-new-lab
cd my-new-lab
python3 -m http.server 8000

Open http://localhost:8000.

No framework, build process or CDN required. The starter folder includes its own index.html, modern-objectivity.css and demo.js. For implementation details see the style specification.

Design specification

  • Colors: light canvas, graphite, peacock-teal accents; full light and dark themes with semantic tokens.
  • Typography: Liberation Sans / Liberation Mono with system fallbacks.
  • Layout: responsive laboratory rail, data panels, 4 px base spacing, deliberate hierarchy.
  • Components: actions, inputs, tables, status, progress, tab navigation, charts.
  • Real demonstrations: JavaScript behavior and generated values, explicitly marked as simulations.
  • Customization: override semantic CSS tokens to develop your lab's own identity.

Design language documentation

MO-13 requires complete user-facing journeys in all 24 official EU languages, including this entire published style guide, handbook and every example. See the central language-access requirement and programming pattern. English Markdown is the authoring source for translated handbook pages; published technical guidance follows the same language requirement. Translations are AI-assisted and await independent language review. Mechanical coverage and source-freshness checks do not certify their linguistic quality.
